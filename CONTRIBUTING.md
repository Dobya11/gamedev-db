# How to contribute

## Adding new items to database

### Open `src/data/resources.json`

Use this template for a valid item entry. Keep `category`, `type`, `pricing`, and `commercialUse` values aligned with the IDs in the matching JSON files.

```json
{
  "id": "",
  "name": "",
  "url": "",
  "description": "",
  "category": "",
  "type": "",
  "tags": [],
  "pricing": "",
  "commercialUse": "yes"
}
```
